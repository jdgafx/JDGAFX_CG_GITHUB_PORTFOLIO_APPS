Applications

Thirteen applications, each in its own directory of the source repository and deployed on Netlify. Each calls models through OpenRouter. The front ends are React and TypeScript built with Vite, and the back ends are Netlify Functions.

  1. app-01-multi-agent-orchestrator

    AgentFlow

    Multi-Agent Research Orchestrator

    Answers a research question from live Wikipedia and Hacker News sources. Four model agents run in a fixed order, then an audit checks every cited sentence of the report against its source and marks it supported, partly supported or not supported.

    Live demoSource

  2. app-02-rag-document-intelligence

    DocMind

    RAG Document Intelligence

    Ask questions about a live Wikipedia article, an arXiv paper or your own PDF. The browser ranks passages with BM25, and each citation in the answer opens the passage with the supporting sentence highlighted.

    Live demoSource

  3. app-03-ai-code-review

    CodeLens AI

    Verified Code Review

    Paste code, load a file from public GitHub or paste a pull request link. A second model pass checks each review comment against the code and keeps, moves or drops it, with a reason that quotes the code.

    Live demoSource

  4. app-04-voice-ai-assistant

    VoxAI

    Streaming Voice Assistant

    Ask by voice or by typing. The reply streams in and the browser starts speaking at the first sentence, with the time to first audio measured and shown. Live weather (Open-Meteo) and Wikipedia lookups feed the answers.

    Live demoSource

  5. app-05-ai-data-analyst

    DataPilot

    AI Data Analyst

    Ask a plain-English question about a live public dataset (USGS, Open-Meteo) or your own CSV, then follow up to refine it. The model writes a query plan and your browser runs it over every row to draw the chart.

    Live demoSource

  6. app-06-llm-playground

    ModelArena

    Blind Model Arena

    Send one prompt to three models, read the answers without names, then vote. A shared Elo leaderboard fills only from real votes. Latency, tokens and cost are measured, and an AI judge’s note is labelled as opinion.

    Live demoSource

  7. app-07-content-pipeline

    ContentForge

    Agentic Content Pipeline

    Turns a topic into a cited piece, grounded in live Wikipedia and Hacker News sources, through five writing steps. Changes between Draft, Edit and Polish are shown word by word, explained, and checked against the text.

    Live demoSource

  8. app-08-vision-ai

    VisionLab

    Multimodal Vision AI

    Ask about a whole picture, about a box you draw on it, or about two pictures side by side. Pick an image from Wikimedia Commons or upload your own; a region question sends the crop at full resolution.

    Live demoSource

  9. app-09-ai-saas

    InsightHub

    npm Download Analytics

    Loads live npm download counts for one to five packages and marks the unusual days. Each spike is matched to the package’s release history, and a streamed explanation has every number, date and version checked against that evidence.

    Live demoSource

  10. app-10-browser-agent

    BrowseBot

    Browser Agent with Visual Replay

    Describe a web task and a model plans the steps. They run in headless Chromium on allowlisted public sites, and a filmstrip replays the real page at each step with the URL, title and text the browser read.

    Live demoSource

  11. app-11-langgraph-research-agent

    GraphScout

    LangGraph Research Agent

    Answers a factual question from Wikipedia with an agent loop, a draft and a critic, and lists its cited sources. You can rewind to the plan or the critic, edit it, and resume the run from that checkpoint.

    Live demoSource

  12. app-12-langgraph-approval-flow

    GraphGate

    GitHub Issue Triage with Approval

    Triages live public GitHub issues. It looks for earlier duplicates and quotes the evidence, then proposes labels, a priority and a reply or “close as duplicate”, and waits for a human to approve, edit or reject. Nothing is posted to GitHub.

    Live demoSource

  13. app-13-langgraph-map-reduce

    GraphSwarm

    LangGraph Map-Reduce

    Splits a Wikipedia article or pasted text into chunks, extracts points from each in parallel and writes a summary that cites its chunks. A coverage map shows which chunks the summary uses, and missed chunks are re-run once.

    Live demoSource
